# AI Textbook RAG API - dependencies
#
# Sized for Hugging Face Spaces free cpu-basic hardware (~1 GB RAM). torch is
# deliberately NOT here: importing it and loading the model costs several
# hundred MB and does not fit. Embeddings use fastembed (ONNX Runtime), which
# runs the same `sentence-transformers/all-MiniLM-L6-v2` weights at a measured
# 239 MB peak RSS and produces numerically identical vectors (cosine 1.0000000,
# max diff 1.2e-07).
#
# To use torch locally instead: `pip install sentence-transformers` and set
# EMBED_BACKEND=sentence-transformers. Vectors stay compatible either way.
