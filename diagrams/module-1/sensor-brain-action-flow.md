# Diagram: Sensor → Brain → Action Flow

## Description
This diagram illustrates the fundamental flow of information in Physical AI systems, showing how sensory input is processed by the "brain" (computational systems) and results in physical action through actuators.

## Key Elements
- Sensors: Various types (vision, IMU, tactile, etc.)
- Processing: Cognitive/decision-making systems
- Actuators: Motors, effectors that produce physical action
- Feedback: Information from action results feeding back to perception

## Flow Description
1. Environmental stimuli are detected by sensors
2. Sensor data is processed by computational systems
3. Decisions are made based on processed information
4. Motor commands are sent to actuators
5. Physical actions affect the environment
6. Results are sensed, continuing the cycle

This represents the core loop of embodied intelligence.
